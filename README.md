# 以數珠為喻 — 《狂密與真密》導覽

純靜態網站（GitHub Pages），入口 `index.html`。3D 以 three.js r128（MIT）＋ OrbitControls ＋ GSAP 3.12.2 呈現，函式庫放在 `vendor/`（不依賴 CDN）。

## 三個頁面（共用同一串念珠，上方按鈕切換）
- **以數珠為喻**：標示導師引文的五個部件（數珠、隔珠、佛頭珠、飾穗、串繩）與完整對應文字。
- **見修行果名相**：四區 76 個名相＋4 顆隔珠全部標出，依珠子位置排成念珠左右兩欄、以引線相連，顏色代表所屬區。持咒主珠位在修、可顯示於行；密宗之中有解脫主珠位在果、可顯示於修。
- **原書導讀**：十七章各配一顆普通數珠；章→節→目分層，節每批 7 節（手機 5 節）換批。上一章／下一章只走 17 個章入口。

## 念珠造型
- 星月菩提子（霧面、細小清晰的星點凹痕）、深紅透亮的紅瑪瑙隔珠、赤陶紅串繩。
- 第四隔珠（環上第 108 顆）較大，兼作佛頭珠；三層三通塔頭沿半徑水平朝外。飾穗自塔頭末端受重力垂下，兩股各串 6 顆中菩提子，尾端為編繩、纏線圓帽、束口與絲線流蘇。

## 珠內閱讀
點數珠／章珠後，鏡頭拉近到原本念珠上的那顆珠，珠子放大並變半透明，文字浮在珠上；左右相鄰珠由串繩相連、同樣半透明，可點擊切換；右側面板保留。

## 串繩與珠孔
每顆珠兩端有珠孔；串繩由 108 段組成，每段連接相鄰兩顆珠的珠孔，珠子漂浮擺動時串繩、佛頭與飾穗一起跟著動。

## 檔案
- 內容資料：`data/content.js`（名相、珠位、跨類顯示、來源標記、校訂註；17 章 160 節〔第七章第三節分上下半〕21 目、頁碼、輯別；序、附錄、跋）。正文 `body`、整理說明 `explanation`、圖片 `image`／`imageCaption` 欄位已預留，目前一律顯示「待補」。
- 資料來源：交接包的「內容種子.json」（整理自《狂密與真密目錄.docx》與「四類名相｜數珠配置確定版」）。
- 狀態、面板、目次、兩種模式：`app.js`
- 3D 念珠、拉近特寫、引線與文字入口：`scene.js`
- 樣式：`style.css`；圖片：`assets/`（禪林背景與觀想情境圖皆為 AI 生成示意，非原書圖版）
- 驗證：`NODE_PATH=$(npm root -g) node tools/verify.cjs file://$PWD/index.html <截圖資料夾>`
